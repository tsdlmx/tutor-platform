# 安全基线（等保 2.0 视角）

本文件把当前实现对照 GB/T 22239-2019《网络安全等级保护基本要求》中与 Web 应用相关的控制项逐条列出，并标注真实状态。**标注为"平台/运维承担"的条目不在本仓库代码内，需要部署方提供证据；标注为"未覆盖"的条目说明还不能上线。**

状态含义：
- **已实现**：仓库代码或随代码交付的配置即可满足。
- **平台/运维承担**：代码侧已给出接口或约束，实际有效性取决于部署（反代、主机、数据库）。
- **部分**：只覆盖了一部分场景，剩余部分在清单中写明。
- **未覆盖**：尚未实现，属于上线阻断项。

## 1. 安全通信网络

| 控制项 | 状态 | 说明 |
| --- | --- | --- |
| 通信传输完整性与保密性 | 平台/运维承担 | 进程支持直接 TLS（`TLS_CERT_FILE` / `TLS_KEY_FILE`）；若在反代终止 TLS，反代必须强制 HTTPS，生产环境启动时会打印明文监听告警。 |
| 仅经受信任代理获取客户端地址 | 已实现 | `TRUSTED_PROXY_CIDRS` 为空时完全忽略 `X-Forwarded-For`；非可信来源直接使用连接地址。 |
| 避免在公网直接暴露后端端口 | 平台/运维承担 | 默认监听 `127.0.0.1:12501`；部署应保证只有反代可达。 |

## 3. 安全计算环境 — 身份鉴别

| 控制项 | 状态 | 说明 |
| --- | --- | --- |
| 唯一身份标识与口令复杂度 | 已实现（客户侧） | 客户口令 6–32 位；管理员沿用旧系统 5–20 位约束。口令以 BCrypt 存储，仅在 `sys_user_auth`（管理员）与客户账户表内。 |
| 登录失败处理 | 已实现 | 管理员：同一（客户端地址, 账号）连续失败 5 次锁定 15 分钟；客户：连续失败 10 次锁定 10 分钟。计数器只按摘要存放，不在 Redis 键中留存账号或地址原文。 |
| 防暴力破解 / 验证码 | 已实现 | 管理员登录需一次性图形验证码（可由配置关闭，未配置时保持必填）；发送验证码、登录、注册、改密均有按地址与主体的限流。 |
| 会话管理与超时退出 | 已实现 | 管理员会话 24 小时、剩余不足 20 分钟自动续期；退出即删除服务端会话，令牌立即失效。客户会话 24 小时并落库可吊销改密即失效。 |
| 传输中口令不以明文留存 | 已实现 | 口令不写日志、不写审计、不进会话记录；错误响应不区分"账号不存在/口令错误"。 |
| 双因素认证 | 未覆盖 | 当前只有口令 + 验证码，未提供短信/OTP 第二因素。等保三级若被要求，需要在上线前补充。 |

## 4. 安全计算环境 — 访问控制

| 控制项 | 状态 | 说明 |
| --- | --- | --- |
| 服务端强制授权 | 已实现 | 迁移到 Go 的管理接口全部经 `adminAuth(permission)` 校验，权限从 PostgreSQL 现查；客户接口经会话校验。 |
| 最小权限 | 已实现 | 管理端按菜单权限串逐项校验，支持 `*:*:*` 超管与通配权限；数据范围（部门）过滤按角色数据范围叠加。 |
| 默认拒绝 | 已实现 | 未匹配路由返回 404；无会话返回 401；无权限返回 403。 |
| 权限变更即时生效 | 已实现 | 每次请求重新加载账号状态、角色与权限，不依赖令牌内声明。 |
| 剩余权限面 | 部分 | 小程序业务接口仍由 Java 提供并沿用旧鉴权，需随迁移复核；React 管理台已全部改走 Go（构建产物中不再包含 `/dev-api`、`/prod-api` 前缀）。 |

## 5. 安全计算环境 — 安全审计

| 控制项 | 状态 | 说明 |
| --- | --- | --- |
| 覆盖每个用户的关键行为 | 已实现 | 管理端写操作在 `sys_oper_log` 落审计（标题、动作、目标、结果、耗时、地址），不含请求体/响应体。 |
| 登录与鉴别事件审计 | 已实现 | `sys_login_audit` 记录成功/失败的登录、注册、改密事件，含掩码后的标识、客户端地址、UA、失败原因码。 |
| 审计记录不可被普通用户修改 | 部分 | 应用层没有修改审计的接口；仍需数据库层限制应用账号对审计表的 `UPDATE/DELETE` 权限（见 §8）。 |
| 审计留存不少于六个月 | 平台/运维承担 | 表已按 `created_at` 建索引；需要运维定时导出归档并设置保留策略，应用不做自动删除。 |
| 审计记录保护个人信息 | 已实现 | 审计只写入掩码标识（如 `a***@example.com`）、地址与原因码，不写口令、令牌、完整邮箱。 |

## 8. 部署方必须补齐的证据（上线阻断）

1. 全站强制 HTTPS，`TLS1.2+`，配置 HSTS；反代把 `/web-api`、`/admin-api` 指向 Go 服务，`/dev-api` 仍指向 Java。
2. 数据库使用独立最小权限账号：应用账号对业务表 `SELECT/INSERT/UPDATE/DELETE`，对 `sys_login_audit`、`sys_oper_log` 只授 `SELECT/INSERT`，禁止 `UPDATE/DELETE/TRUNCATE`。
3. `JWT_SECRET` 使用 64 位十六进制随机串并纳入密钥管理，不写入镜像与仓库。
4. 审计与日志留存 ≥ 6 个月，配置归档与告警（登录失败激增、审计写入失败）。
5. 主机与容器基线：最小镜像、非 root 运行、只读根文件系统、限制出网。
6. 小程序业务接口仍由 Java 提供，上线前须复核其鉴权与限流；React 管理台侧已无 Java 依赖。
